# 定时循环音频播放器

一个网页版音频播放器：导入手机里的某个音频，每隔 N 秒播放 M 秒，循环往复。

## 功能

- 从手机选择任意音频文件（mp3、m4a、wav 等），不上传、不联网
- 自定义播放时长与间隔时长，运行时即可调整
- 间隔语义：从上次播放结束算起，静默 N 秒后再播 M 秒
- 素材短于播放时长时可自动循环补齐
- 屏幕唤醒锁，防止播放时自动熄屏
- 运行状态显示：当前阶段、剩余秒数、已运行时长、已完成轮数

## 怎么用

1. 手机浏览器打开页面
2. 点「选择手机里的音频文件」挑一个音频
3. 填播放时长和间隔时长
4. 点「开始播放」

播放期间请让页面保持在前台，不要手动锁屏，否则浏览器会暂停音频。

## 计时精度

播放节奏由 Web Audio 的音频硬件时钟驱动，通过 `AudioBufferSourceNode.start(when, offset, duration)`
预调度未来的播放事件，不使用 `setInterval` 触发播放。

这样做的原因是 JavaScript 定时器的回调会被主线程的渲染、垃圾回收等任务推迟，
且误差会逐轮累积，长时间运行后节奏会明显漂移。改用音频时钟后，所有播放时间点
在调度时就已确定，不存在累积误差。

## 关于 HTTPS

页面用到了 Screen Wake Lock API，浏览器要求安全上下文（HTTPS）才允许使用。
用 HTTP 打开时播放功能正常，但无法阻止屏幕熄灭，需要把系统「屏幕超时」调到最长。

## 本地运行

```bash
node server.js
```

默认同时提供 HTTP（8080）与 HTTPS（8443）。HTTPS 需要目录下存在 `cert.pfx`，
该文件是自签名证书与私钥，已在 `.gitignore` 中排除，不会入库。

生成自签名证书后可访问 `https://<本机局域网IP>:8443`，
浏览器提示证书不受信任时选择「高级」再「继续前往」。
